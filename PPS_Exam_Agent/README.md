# PPS-Exam-Agent

🚀 PPS-Exam-Agent is an AI-powered study assistant designed to help candidates prepare for the Provincial Planning Services Officers (BPS-17) competitive examination.  
It intelligently routes your queries to expert subject tutors, provides study plans, practice questions, and exam preparation tips.

## Features
- Subject-specific AI tutors (English, Economics, Science, Islamiat, Pakistan Studies)
- Smart triage agent to route questions
- Viva Voce and essay preparation support
- Built with Agentic AI workflow
- Powered by Muzzammil Shahe 🕵️, Agentic Developer

## Getting Started
1. Clone the repository.
2. Set up your environment variables (`MODEL_NAME` and `API_KEY`).
3. Run the agent using your preferred server or deployment setup.
